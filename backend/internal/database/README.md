# Sqlite3 database for the development of the beef tracking software

## Why Sqlite3 :
* develop with sqlite3 since it is faster and because it is deployed
locally we dont have to worry about rate limits while testing
* We will migrate to supabase once the development is done and the app is production ready

## Why Golang :
* Golang is a simple language which I am familiar with and it has alot of packages for
backend development 
* Golang also integrates with Sqlite3 smoothly and is faster
